This is a sample blog post. Write in plain markdown.

To add a new post, create a file in `_posts/` named `YYYY-MM-DD-title.md`
with front matter like the top of this file. It appears on the blog page
and the front page automatically.

Images go in `assets/images/` and are embedded like this:

```markdown
![Description of image](/assets/images/example.jpg)
```
